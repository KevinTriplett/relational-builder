# app-trust-tasks — test coverage matrix

Written by the Phase 2 test agent from `SPIKE-SPEC.md` (as amended, Changelog C-1…C-24) and
`DESIGN.md` §2–§3 only. Run: `npx vitest run`. Type-check: `npx tsc --noEmit -p tests/tsconfig.json`.

Every suite goes through `fake-postgrest.ts` (DESIGN §3, P1–P13). The fake records any unmodelled
call as a contract violation; `helpers.ts` fails every test whose code under test made one (S-12),
even if the code caught the error and answered `unavailable`. `tests/setup.ts` replaces global
`fetch` with one that throws, so a real network call fails the test (NF-2). All time comes from an
injected clock starting in 2031, so a module that reads the real clock refuses every document.

## Spec ambiguities

All twelve raised in Phase 2 were resolved by the design agent (Changelog C-25…C-36); the tests follow the resolutions.

1. Port in the default VID — **resolved C-25**: `did:web:<hostname>` + `%3A<port>` for an explicit non-default port, shared by S-30 and S-71. Test changed (`localhost:54321` → `did:web:localhost%3A54321`; `:443` dropped); S-71 grep now requires `.hostname` and `%3A`.
2. Where the guidance is appended — **resolved C-26**: `trustSigninConnected(vars)` tested directly; ChatPanel use checked by grep. Row upgraded to covered.
3. `issuedAt` format in the helper — **resolved C-27** (confirmed as tested).
4. `created` in `signIn` — **resolved C-28** (confirmed as tested).
5. Fetch rejection in `signIn` — **resolved C-29**: rejected fetch → `('transport', true, 0)`; non-JSON / non-error-JSON non-2xx → `('transport', status >= 500, status)`. Tests added.
6. `Member` type hunks in `app-data` — **resolved C-30** (confirmed as tested).
7. `did:key` subject check — **resolved C-31**: full base58 pattern, no fragment, decodes as Ed25519. Cases added (`did:key:z6Mk0OIl`, `<did>#frag`, `did:key:z6Mkabc`, trailing space).
8. `malformedRequest` retryability — **resolved C-32** (`retryable: false`, confirmed).
9. Extended-code status — **resolved C-33** (422, confirmed).
10. `// SPIKE:` count — **resolved C-34**: per-file minima now asserted.
11. `select=` columns — **resolved C-35** (exact set, confirmed).
12. Filter-value encoding — **resolved C-36**: store-level and core-level `+&=#` sessionId tests added (must be `notFound`, no contract violation).

New ambiguities: none.
